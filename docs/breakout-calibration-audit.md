# C突专项分桶回测报告

> 日期：2026-09-07
> 策略版本：`2026.09.06.1`
> 数据口径：前复权日线，`DATA_START_DATE = 2025-04-29`

## 目的

`docs/backtest-entry-model-audit.md` 已确认：C突在信号日收盘口径下略正，但切换到次日开盘口径后明显被压缩。本文继续拆分 C突的亏损来源，判断问题到底来自：

- 次日高开追涨；
- 突破当日涨幅过大；
- 距离 MA20 过远；
- 量比过热；
- 风险拆分中的过热项。

本报告只做数据审计，不直接修改 `strategy.py` 阈值。

- 历史文件：本地 `.cache/history` 中前 2400 个前复权日线缓存文件

- C突信号数：3764

## 次日缺口分桶

| 次日开盘 | 样本 | 当前均值收益 | 次日开盘均值收益 | 次日模型更差比例 |
| --- | ---: | ---: | ---: | ---: |
| 平开 `[-1%, 1%)` | 2618 | 0.226% | 0.112% | 54.43% |
| 低开 `<= -1%` | 516 | -1.529% | 0.010% | 30.81% |
| 高开 `[1%, 3%)` | 384 | 1.475% | -0.726% | 78.39% |
| 大幅高开 `>= 3%` | 177 | 4.868% | -0.081% | 79.10% |

判断：

- 高开追涨是最明确的问题。高开 1% 以上时，当前模型看起来很好，但次日开盘口径显著变差。
- 低开并不差，说明“突破后次日给低吸价”反而更接近可执行机会。

需求建议：

- C突候选不应只看突破成立，还要标记“次日追高风险”。
- 若后续支持盘中或次日计划，C突更适合“突破确认后等待不高开的执行价”，不是无条件次日开盘追。

- 当日涨幅 >= 6% 时，事件收盘收益最好看，但次日开盘转负，典型吃到当日动量。

## 策略建议

### 保留

- 保留 C突。它不是无效信号，而是需要执行层过滤。
- 保留“前高突破”作为 C突必要条件。
- 保留风险拆分，尤其是过热分。

### 调整

1. C突增加“追高风险标签”，先不直接删除信号。
2. 当次日高开 >= 1% 时，候选详情应提示“等待回踩确认/不追开盘价”。
3. 当突破当日涨幅 >= 6% 或距 MA20 >= 10% 时，C突不应作为强参与候选，可降级为观察或要求回踩。
4. 当过热分 = 3 时，C突应降权，除非同时出现更强的板块外生强度与低风险结构。
5. 量比最佳区间初步看是 1.5-2.5，极端放量不应加分。

## 下一步需求

### P1-1B-1 C突追高风险解释

在候选结果里增加 C突执行风险解释，不改变触发逻辑：

- 次日高开风险；
- 当日涨幅过大；
- 距 MA20 过远；
- 过热分 3。

验收：

- C突候选详情能解释“突破成立，但为什么不适合追”。
- 不把风险标签误写成卖出建议。

### P1-1B-2 C突降权实验

在不删除 C突的前提下做实验分支：

- `return_pct >= 6` 降权；
- `close / ma20 - 1 >= 10%` 降权；
- `risk_heat_score >= 3` 降权；
- `next_open_gap >= 1%` 只能在次日计划层提示，不应用于信号日扫描。

验收：

- 输出降权前后候选数、平均收益、胜率、重叠率。
- 若进入正式策略，必须 bump `SCAN_STRATEGY_VERSION`。

### P1-1B-3 执行价模型

C突正式交易计划不应默认为次日开盘追入，应优先生成：

- 突破价；
- 回踩观察价；
- 失效价；
- 高开禁追提示。

验收：

- `trade_plan.py` 能区分“信号成立”和“执行许可”。
- 候选池仍可展示 C突，但交易计划可以给出 forbidden/wait。

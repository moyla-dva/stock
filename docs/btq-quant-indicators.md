## 〇、总纲：这套方法论的决策链

课程反复强调的执行次序（第 9、26 课），与本项目 `market_permission → trade_plan` 的架构同构：

```
第一层  波幅时钟   —— 现在值不值得看？（坍缩=倒计时开始）
第二层  收益风险比 —— 这笔交易值不值得做？（≥2:1，最好 3:1）
第三层  多空格局   —— 方向是什么？（力度/年线/大周期滤网，只排除不预测）
第四层  时机结构   —— 位置在哪？（分型/矩形/双分型排列）
第五层  触发器     —— 这一刻行动！（指标 = Trigger，不是预言机）
```

**技术指标的正确定位：Trigger。** 没有完成前四层判断时，任何指标信号都没有操作含义。

## 一、方向/格局层（喂给 `market_permission` 与单股综合研判）

### 1.1 多空力度（威廉力度）

- **公式**：`多头力 = 收盘价 − 最低价`（C−L）；`空头力 = 最高价 − 收盘价`（H−C）。
- **用法**：单根 K 线的买卖方力量痕迹；可做 N 日累计、比值或与均值比较。空头力突然放大 = 惯性向下强，此时任何底分型都不可逆势做多。
- **前提**：只在有方向的市场有效，横盘中两条线来回交叉、信号无效——**必须先判方向再用**。
- **出处**：第 6 课（1965 年威廉姆斯原始定义）。
- **落点**：`indicators.py` 新增计算；结果进单股研判与候选评分。
- **验证要点**：横盘市中应验证"信号无效"（期望收益≈0），作为使用前提的数据背书。

### 1.2 威廉 %R 50 中轴

- **公式**：`%R = (HH_n − C) / (HH_n − LL_n) × 100`（n 常用 10）。
- **用法（颠覆式）**：不使用超买超卖阈值（趋势市中钝化必死），只看 **50 中轴**：趋势向上时 %R 下穿 50 = 做多时机；趋势向下时上穿 50 = 做空时机；**陡峭穿越** = 价格重心摆动（与"突然出现方向性阳线"等价的两种观察）。
- **前提**：先判断大趋势（用年线/多空力度）；震荡市中 50 附近来回穿越，信号无效。
- **出处**：第 1、9 课。
- **落点**：`indicators.py` 新增 williams_r；50 穿越事件进 `strategy.py` 触发层。

### 1.3 年线格局（非 A 参照系）

- **公式**：`C > MA250 且 MA20 > MA60 → 多头格局`；反之偏空。两个条件同时满足才标记，缺一即观望。
- **理念**："不能用 A 预测 A"——所有价格衍生指标都是 A；年线是时间维度的独立参照。均线**判格局不判择时**（择时靠分型/起爆点）。
- **出处**：第 19、23 课。
- **落点**：`market_permission.py` 或综合研判的格局判断位。

### 1.4 趋势双确认

- **判定**：下跌趋势 = 高点不断下移 **且** 低点不断创新低，两者缺一不可；只有高点下移 = 区间震荡。
- **出处**：第 5 课。
- **落点**：`technical_structures.py` 的趋势状态判定；防止单条件误判。

## 二、波动/时机层

### 2.1 波幅坍缩（威廉时钟）——项目已实现，按下表对照补全

- **判定**：`成交量 < 近半年（或一年）均量` **且持续 > 15 个交易日** → 坍缩开始；坍缩之后必然扩大（方向未知），扩大之后未必坍缩（非对称）。
- **用法**：坍缩 = "开始研究"信号，**不是入场信号**；坍缩后方向由 1.1/1.3 判断。
- **布林通道的唯一用途**：肉眼观察带宽宽窄（宽=运动，窄=收缩）；上下轨不是支撑压力，不做触碰交易。
- **出处**：第 7、9 课。
- **现状**：`technical_structures.build_williams_clock` 已实现（compression_score / volume_dryness_days / countdown_state）——**对照补全**：坍缩的量能基准（半年/年均量）与 15 天持续阈值是否与笔记一致。

### 2.2 起爆点（趋势起爆价）

- **公式**：
  ```
  向上起爆点 = 今日开盘价 + (昨日最高价 − 昨日收盘价) × N
  向下起爆点 = 今日开盘价 − (昨日最高价 − 昨日收盘价) × N
  ```
- **关键设计**：波幅刻意取 **最高−收盘**（卖方当日实际抛压），不是最高−最低（那含多空拉锯全程）。抛压小 → 次日易突破。
- **参数**：N 按品种回测确定（威廉姆斯有品种参数表）；N=1 为最简版。
- **前提**：结合"特定交易日"筛选（见 2.4 周一效应），不是每天都适用。
- **出处**：第 10、12 课。
- **落点**：`trade_plan.py` 的 entry 触发价 / `strategy.py` 触发层。
- **纪律**：突破就行动（见护栏 3.3），错了止损，不做真假突破预判。

### 2.3 开盘 30 分钟波幅规则（五条短线原则）

1. 开盘买入，持有到收盘，除非触发止损；
2. 开盘 30 分钟内跌幅未超过**近 5 日下探波幅均值** → 可以买（开盘即大跌 = 当天可能大阴线）；
3. 对称：开盘 30 分钟内涨幅未超过**近 5 日上探波幅均值** → 可以卖；
4. 越早涨停越强（开盘 30 分钟内涨停 = 主力接盘宣示；尾盘拉 = 资金不足）；
5. 双向大幅波动 → 立刻撤退（胜负未分）。
- **出处**：第 8 课。**落点**：盘中规则，需要分钟线（项目已有新浪/TDX 分钟数据）。

### 2.4 周一效应与交割日规避（日历过滤器）

- **周一效应**：周一开盘消化 ≈60 小时信息（其余交易日 ≈12 小时）→ 波幅系统性更大。实战模型：只在周一交易、每周最多 1 次、开盘起爆点突破入场、持有到收盘。参考回测：51.85% 胜率 ≈ 赌场优势逻辑（可复制 + 足够次数 = 正期望）。
- **交割日规避**：股指 IF/IH/IC 交割日 = 合约月**第三个自然周五**（自然日计，含假期）；交割日附近价格信号是换仓扰动，不跟随。
- **出处**：第 12 课。
- **落点**：新增 `market_calendar.py` 或并入 `scan_market_context.py`。

### 2.5 持仓时间

- **短线最优持仓 2-5 个交易日**；日内波幅太小无利可图；风险由止损与仓位控制，不由缩短持仓时间控制。
- **出处**：第 8 课。**落点**：`trade_plan.py` 的持仓周期预期字段。

## 三、形态/触发层（喂给 `strategy.py` 触发层与 trade_plan 的 entry）

### 3.1 威廉分型（高点/低点的无歧义定义）

- **底分型**：连续 3 根 K 线，中间那根的**最低点**低于左右两根的最低点；顶分型对称（中间最高点高于两侧）。
- **包含关系剔除**：相邻 K 线出现内包含（一根高低点完全在另一根内）或外包含（完全包住）时，方向未定，**该 K 线不计入分型判断**。
- **叠加**：三个底分型中，中间分型低点低于左右两个分型低点 → 更大级别低点。两分型之间的一段 = 一个 **Swing**（后续价格结构分析的基本语言）。
- **出处**：第 4 课。
- **落点**：`technical_structures.py` 新增威廉分型检测（与现有 MACD 背离是两回事）。

### 3.2 双底分型反转排列（比单分型高一阶）

- **判定**：第一个底分型（较低低点）→ 价格反弹 → 第二个底分型**低点抬高** → 反转结构成立。单个底分型无操作意义；低点抬高 = 空头无法继续压价、开始减仓。
- **变体（洗盘）**：底分型右侧出现多个低点，只要**不破关键支撑**，每个低点 = 一波洗盘，洗得越多浮筹越干净，是更可靠的底部信号而非失败。
- **出处**：第 5、9 课。
- **落点**：分型检测之上的一层排列识别。

### 3.3 阴包阳创新低（观察开关）

- **判定**：今天为阴线 **且** 今高 > 昨高 **且** 今低 < 昨低（外包含）**且** 今低创近期新低。
- **含义**：自然下跌中每天应在更低位置运动；今高 > 昨高说明**开盘后有人主动买入**（力量尚不足以压住卖盘）→ 资金介入的行为痕迹。
- **用法**：这是**开始观察的开关**，不是入场信号。从这根 K 线起观察分型排列（3.2），低点抬高 + 入场信号出现才买。
- **出处**：第 13 课。
- **落点**：`strategy.py` 触发层事件。

### 3.4 攻击日形态（三 K 入场 + 结构止损）

- **结构**：① 阳线 → ② 吞没阴线（高低点均超出①、外包含、创近期新低）→ ③ 价格**突破②的最高点时入场**。
- **止损**：② 的**最低点以下**（整根吞没阴线 = 真实风险空间）。**反对固定比例止损**（1-2% 会被精准洗出）；阴线太大风险超限 → 放弃这笔交易。
- **与"多头炮"的区别**：中间阴线是否吞没（外包含）+ 是否等突破确认（多头炮看排列就买，攻击日等突破）。
- **入场后计划不可变**：理由、止损、目标入场前定，入场后不讨论。
- **出处**：第 14 课。
- **落点**：`strategy.py` 触发事件 + `trade_plan.py` 的 entry/stop（结构止损）。

### 3.5 缺口封闭（反转概率信号）

- **判定**：跳空低开（开盘 < 昨日最低）后，盘中价格回升至**昨日收盘价附近** = 缺口封闭 → 短线反转概率陡增。缺口背后 = 恐慌性抛盘一次性释放，缺口越大反转潜力越大。
- **限制**：盘中信号，瞬时性——封完可能继续涨也可能再跌，提高的是概率不是保证；快进快出。
- **出处**：第 15 课。
- **落点**：盘中信号（分钟线），进单股研判的事件面板。

### 3.6 矩形框架（一切皆是矩形）

- **统一律**：三角形/楔形/旗形/圆弧 = 没做成的矩形，全部按矩形处理；不必识别十几种形态。
- **可操作性规则**：
  1. 突破哪边就去哪边（右侧交易），**不分真假突破**（"有效突破"是未来函数），错了止损；
  2. **矩形内部不操作**——除非矩形高度 > 该品种单日涨跌幅（主板 10%、创业/科创 20%）；矩形内 = 随机漫步，期望值≤0；
  3. 突破后**回踩矩形内是常态**（大多数品种如此）；止损 = **矩形内最低收盘价（C 点）以下**——矩形是主力成本区，不破 C 点回落都是洗盘；小止损反而会被精准洗出；
  4. 放量是陷阱、缩量是信号（放量方向无法区分建仓/出货）；
  5. 高位矩形（出货或坚守）与低位矩形（建仓或骗局）无法在形成中区分——四种可能，等价格行为裁决。
- **出处**：第 21、22 课。
- **落点**：`technical_structures.py` 矩形检测 + `trade_plan.py` 的 C 点止损。

## 四、风控/仓位层（trade_plan 的 position/stop 域——**当前最薄的板块**）

### 4.1 仓位公式

```
数量 = 账户余额 × 风险比例 ÷ 每手（每股）最大亏损
```

- 首笔仓位 **3%**（不确定这次对不对，但确定还有钱抽下一个信封）；
- 分批建仓：总手数 ÷ 3，每次 1/3；
- 禁用凯利公式（杠杆市场亏损无上限 + 胜率不稳定 + 亏钱加码 = 爆仓路径）。
- **出处**：第 2、17 课。**落点**：`trade_plan.py` position 域。

### 4.2 收益风险比门槛

- **≥2:1，最好 3:1**；3:1 时即使胜率 50% 也是正期望。
- **线段等分法**：波段最高点 ─ 年线 的线段四等分，"下 1 份风险 / 上 3 份收益"的分割点 = 理论买入区。
- 出处：第 26 课。**落点**：`trade_plan.py` 入场前置校验；不满足 → forbidden_reasons。

### 4.3 本金重新计算法（峰值回撤即亏损）

- 每时每刻把**当前账面总值视为新本金**：100 万涨到 130 万后，130 万就是新本金；跌回 125 万 = 已亏 3.8%，触发减仓——**不是**"本金 100 万没亏"。
- 盈利加仓 + 亏损减仓都是人性，只是"亏损"要定义为**市值从峰值回落**。
- 出处：第 17、18 课。**落点**：持仓管理模块（若后续开发持仓跟踪）。

### 4.4 30% 法则与底仓/交易仓双轨

- 任意时刻只用 **30%** 资金交易 → 永不爆仓、永远在场内；
- **底仓**做趋势（矩形低位建立，止损 C 点下）；**交易仓**做波段（矩形高位/突破后加仓，拐点兑现回收现金）——实现"上涨时有股可卖，下跌时有钱可买"。
- 出处：第 18、21 课。**落点**：持仓框架（远期）。

### 4.5 结构止损汇总（替代固定比例止损）

| 入场形态 | 止损位 |
|---|---|
| 攻击日做多 | 吞没阴线最低点以下 |
| 矩形突破做多 | 矩形内最低收盘价（C 点）以下 |
| 底分型做多 | 分型低点以下 |
| 反转结构做多 | 反转结构最低点以下 |

止损必须放在"对手洗盘洗不到的地方"；嫌止损太远就放弃这笔交易，不许缩小。

## 五、工程护栏（量化开发纪律——直接约束本项目）

1. **昨日收盘价原则**：用昨日已定数据触发今日信号，杜绝"当日收盘价触发当日信号"的未来函数（波浪/缠论解释过去如神、实盘打脸的根源）。**直接呼应本项目 backtest.py "信号日+5 日"口径的问题**——回测评估点应为触发价而非信号日。
2. **胜率健康区间 30%–50%**：>60% = 过拟合嫌疑；90% = 几乎必然存在未来函数；<10% = 策略本身有问题。
3. **框架固定不调参数**：回测不好改框架逻辑，不调参数（参数为历史量身定制，对未来无预测力）。
4. **放量不作为买入依据**：放量方向无法区分建仓/出货（大资金拆单模仿散户）；缩量才是变盘信号。成交量的正确用法 = **筛选值得关注的市场**（放量 + 指数年线上方 → 开始研究），不是买卖依据。
5. **时间周期是幻觉**：时间参数样本外失效，不做日历性规律（周一是例外——它有信息量机制解释）。
6. **形态记忆悖论**：教科书形态越众所周知越被对手利用——回测自己数据上的形态胜率，而不是背形态。
7. **机械执行优于临场发挥**：量化固定模式，状态差时不被情绪污染（奇衡与威廉姆斯在此点立场相反，奇衡反对"结合智慧"）。

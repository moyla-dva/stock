## 策略建议

### 保留

- 保留 P2 的事实层字段与候选解释。
- 保留 Williams %R 50 中轴穿越，但必须按信号类型解释。
- 保留多空力度占优，但不作为全局方向过滤。

### 不建议

1. 不建议把 `%R 50 下方` 直接设为统一买入加分；
2. 不建议把 `空头力占优` 直接设为统一风险扣分；
3. 不建议在未区分 C突/C回/C观前，把 P2 接入 `market_permission`；
4. 不建议因 `%R <20` 继续给 C突加分，样本显示它更像接近高位后的追价状态。

### 建议实验

1. **C突专用确认实验**：`williams_r_cross_bull` 加权，`williams_r < 20` 不加分或标记追高风险。
2. **C回解释修正**：C回里的 `%R 50-80`、空头力占优应解释为“回踩空间”，不直接警告。
3. **C观降级实验**：C观需要更强结构条件，否则继续保持观察，不升级参与。
4. **组合消融回测**：分别测试 C突、C回、C观接入 P2 权重后的候选数、胜率、均值收益、最大亏损和重叠率；通过后再 bump `SCAN_STRATEGY_VERSION`。

## 结论

P2 指标合理，但它不是“统一方向滤网”，而是“信号语境解释器”。当前最稳妥的产品定位是：

- C突：用 Williams %R 中轴穿越确认突破质量，同时防止极近高位继续追价；
- C回：把偏空侧理解为回撤状态，不误判为风险；
- C观：只做解释，不承担入场升级。

下一步若继续策略实现，应先做 P2-2 消融实验，再决定是否进入正式评分与版本升级。

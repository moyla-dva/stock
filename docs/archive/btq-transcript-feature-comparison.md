# B-TQ 文稿驱动功能映射与当前软件对照

范围：`/Users/vainve/Documents/Codex/2026-05-24/users-vainve-b-tq-library/reading_order_excluding_qiandao.tsv` 中 110 份文稿，沿用此前约定，排除「千刀千法」。

目标：不是把文稿压缩成大纲，而是把每份文稿转成软件可落地的功能、规则细节、校验点，再和当前「股票短线分析软件」对比。

## 总体结论

当前软件已经具备「行情数据 -> 指标 -> 扫描候选 -> 主线/结构展示 -> 单股确认 -> 数据治理」的基础链路，但它还不是文稿意义上的交易系统。

文稿要求的软件核心不应该是“推荐股票”，而应该是：

1. 先判断今天有没有交易权限。
2. 再判断市场是否有鱼、是否有持续方向。
3. 再确认板块中是否有领头羊，龙头股是否可配置。
4. 再把单股转成交易计划：触发、止损、仓位、盈亏比、失效条件。
5. 最后记录执行和复盘，验证规则是否有优势。

当前软件的主要缺口：

- 缺「交易计划卡」：止损价、仓位、单笔风险、总风险、移动保护、禁止交易原因。
- 缺「交易权限」：行情阶段、资金环境、是否一日游、是否允许追击、是否只观察。
- 缺「领头羊 vs 龙头股」的区分：现在有主线/候选，但没有按文稿拆成领头羊择时、龙头股配置。
- 缺「坐标参照系」：没有把 A 与 B、个股与板块、领头羊与龙头、指数与个股做相对强弱/价差判断。
- 缺「策略优势验证」：已有部分回测统计，但没有样本外、坏运气、过滤损耗、规则优势、交易成本的完整验证台。
- 缺「历史/宏观/基本面风险层」：美元、利率、财政、信用、产业景气、商业模式、空头攻击点等还没有进入交易权限。

## 文稿抽出的产品结构

### 1. 交易权限层

对应文稿：股票作手操盘术 1-10、专业投机原理 11-28、以短线交易秘诀为生 35-69、卖艺 71-88、伟大博弈 89-110。

软件应先回答：

- 市场是否有鱼：指数、成交额、资金流、板块宽度、持续性是否支持交易。
- 当前行情阶段：底部无人问津、启动试探、火爆扩张、尾声拥挤。
- 是否一日游：单日强度不能直接升格为主线，必须看连续性、宽度、代表股、回踩承接。
- 是否有不确定性：即使风险还未落地，只要出现不可衡量的不确定性，也要主动降低暴露。
- 是否允许进攻：强主线可参与，发酵只观察，分歧先控风险，弱轮动只看低位修复。

当前软件：半有。`market_lines.py` 已有阶段和参与剧本，但缺硬门槛，尤其缺“一日游降级”和“禁止交易”。

### 2. 主线、领头羊、龙头股

文稿里的“主线”不是单纯板块名。更准确的链条是：

- 先有不可阻挡的价格运动。
- 价格运动背后有资金和筹码结构。
- 板块若没有领头羊，板块没戏。
- 领头羊是信号和营销成本，不一定是好公司。
- 龙头股是配置对象，通常流动性和基本面更稳。
- 小资金可追领头羊，但代价是止损；稳健做法是用领头羊择时，用龙头股配置。

软件应增加：

- 领头羊识别：同板块涨幅、速度、创新高、成交额扩张、连续性、主动带动性。
- 龙头股识别：行业地位、流动性、机构承载、基本面质量、板块权重。
- 领头羊状态机：继续创新高、滞涨、掉队、补涨股反超、大票补涨。
- 板块有效性判断：无领头羊则只观察；领头羊熄火则降低板块权限。

当前软件：半有。已有主线和候选池，但没有领头羊/龙头股双轨。

### 3. 单股交易计划

文稿反复强调：进场前必须知道止损位和愿意亏多少；买入从一开始就是为了卖出。

软件应新增「交易计划卡」：

- 计划类型：主升浪、关键点、回踩确认、三重滤网、2B、矩形突破、底分型、起爆点。
- 入场触发：突破昨日高点、升穿关键点、突破矩形、分型颈线、三重滤网第三层。
- 止损价：前一日低点、矩形下沿、底分型极点、年线、关键点失效位。
- 仓位：账户规模、单笔风险、总风险、止损距离倒推数量。
- 盈亏比：至少显示潜在亏损、潜在目标、R 倍数。
- 移动保护：有浮盈后止损上移，保护脚下利润。
- 失效条件：买入理由不存在、关键点破坏、领头羊熄火、主线降级、风险扩散。
- 禁止交易原因：止损过远、无领头羊、无持续性、左侧却想上杠杆、成本过高、盈亏比不合格。

当前软件：缺。已有综合信号和风险信号，但没有把信号转成可执行计划。

### 4. 结构工具

文稿里的技术结构不是为了预测，而是为了行动。

应进入软件的结构清单：

- 主升浪：高点创新高、低点抬高、资金持续流入、浮盈快速扩大。
- 关键点：错了小亏，对了快速有浮盈安全垫。
- 年线：大格局过滤，年线上/下采用不同交易权限。
- 左侧/右侧：左侧只试错，不上杠杆；右侧才可加仓或放大仓位。
- 2B 法则：趋势失效动作，不是顶底预测。
- 矩形：成本区/筹码交换区，内部随机，突破边界才有动作。
- 威廉分型：用三根 K 线定义可计算高低点。
- 威廉时钟：不用日历时间预测周期，而用波幅收缩/扩张识别“机会倒计时”；布林通道只作为观察张弛波幅的工具，不用上下轨直接做买卖。
- 起爆点：用波动扩张识别短线爆发，不负责长期方向。
- 三重滤网：大周期排除方向，中周期找候选，小周期突破执行。
- 价量关系：成交量不能单独决定方向，只能作为行为证据。

当前软件：半有。已有 K 线、MACD、KDJ、ADX、布林、VWAP、背离、60m，但缺结构解释、结构止损和结构触发；布林目前只是传统指标计算，没有威廉时钟的带宽收缩分位、成交萎缩持续天数、收缩后扩张提示。

### 5. 出场与风控

应新增：

- 鳄鱼法则：错了立刻断，不摊低成本，不复仇交易。
- 止损六要点：避开大众止损位、周期越长止损越宽、日内新手禁区、用大格局辅助、有浮盈设移动保护、参考第一个底分型极点。
- 卖飞评估：卖飞不是错，回避风险优先于吃完行情。
- 底部斩仓判断：不是便宜就买，而是看是否有中长线资金承接集中认输筹码。
- 浮盈保护：从亏损止损变成利润保护。

当前软件：半有。`strategy.py` 有 stop_loss、take_profit、trend_break，但规则比较固定，未接入计划周期、结构止损、移动保护细节。

### 6. 仓位管理

文稿强调重仓不是 all in，而是多笔正确交易叠加。

应新增：

- UBW 分段建仓：第一笔试仓，市场证明后第二笔、第三笔。
- 每一笔单独管理：每笔都有入场价、止损、风险、退出条件。
- 2%/6% 风险红线：单笔风险、组合总风险必须可计算。
- 杠杆约束：左侧禁杠杆，右侧才可考虑；局部右侧失效先处理杠杆。
- 空仓也是仓位：无环境、无触发、无盈亏比时空仓。

当前软件：缺。

### 7. 策略优势验证

文稿对“策略是否有优势”讲得很细：过滤器减少错误，也会过滤机会；指标越多不等于越强；策略要经受坏运气。

应新增：

- 策略实验台：规则定义、参数、样本内、样本外、交易成本。
- 过滤损耗：新增过滤器减少多少交易、减少多少亏损、错过多少机会。
- 坏运气测试：连续亏损、最大回撤、低胜率区间。
- 规则优势：进出场组合是否有正期望，而不是只看单个买点。
- 交易日志：每笔交易归因，记录是规则亏损还是执行亏损。

当前软件：半有。已有部分信号回测统计，但不是完整策略实验台。

### 8. 基本面、空头思维、历史与宏观

文稿不是只讲技术。它要求用宏观、历史、产业、基本面、空头思维来防被骗。

应新增：

- 宏观环境：利率、美元、财政、信用、商品周期。
- 家国/政策方向：净持仓方向不得逆政策和国家利益。
- 基本面穿透：钱从哪里来、成本在哪里、谁付钱、现金流是否真实。
- 空头攻击点：高估、造假、高杠杆、监管处罚、关联交易、商业模式脆弱。
- 历史案例库：泡沫、逼空、挤兑、财政救助、信用扩张、操纵案。

当前软件：基本缺失。现在只有股票画像、概念库和概念图谱，还没有宏观/历史/空头检查。

## 改造优先级

### P0：先补交易计划

最贴近文稿，也最能纠正当前软件偏“信号展示”的问题。

必须字段：

- 当前是否允许交易。
- 入场触发。
- 止损价。
- 计划亏损金额。
- 仓位。
- 盈亏比。
- 移动保护。
- 失效条件。
- 禁止交易原因。

### P1：把今日主线改成交易权限

主线不是买入答案，而是权限系统。

新增规则：

- 单日强度只给「事件脉冲」。
- 连续 2-3 日、宽度扩散、领头羊确认，才可升为「发酵方向」。
- 领头羊继续创新高、龙头股承接、风险未扩散，才可给「确认主线」。
- 风险池压过机会池，降级为「分歧控制」。

### P2：领头羊/龙头股双轨

新增两个对象：

- 领头羊：择时信号。
- 龙头股：配置承接。

展示时不要只说“这个板块强”，而要说：

- 谁是领头羊。
- 谁是龙头股。
- 领头羊是否仍在带路。
- 龙头股是否正在补涨或出货。
- 领头羊熄火后板块是否仍可参与。

### P3：威廉时钟/波幅倒计时

把布林从普通指标改成观察许可：

- `compression_score`：布林带宽或真实波幅处在历史低位。
- `volume_dryness_days`：成交量持续低于半年或一年均量的天数。
- `countdown_state`：是否进入“收缩倒计时”。
- `direction_unknown`：明确不预测向上还是向下。
- `requires_route_confirmation`：必须再接主线、三重滤网、领头羊、突破触发。
- `post_compression_expansion`：收缩后是否已经出现波幅扩张，若扩张失败则继续观察。

这个模块不产生买卖信号，只决定扫描列表里哪些标的值得开始研究。

### P4：策略实验台

让每个规则能被验证：

- 胜率。
- 平均盈亏。
- 最大回撤。
- 连续亏损。
- 过滤前后差异。
- 样本外表现。
- 交易成本。

### P5：宏观、基本面、历史风险层

这部分不用第一版就很重，但必须进系统：

- 利率/美元/信用周期。
- 政策与家国原则。
- 基本面穿透。
- 空头攻击点。
- 历史相似案例。

## 下一步落地建议

不要继续先加指标。下一步应该先做两个文件级改造：

1. 新增后端 `trade_plan` 模块：把单股信号转成计划、仓位、止损、禁止交易原因。
2. 改造主线输出：把 `market_lines` 的阶段从展示文案升级为交易权限，增加一日游过滤和领头羊/龙头股字段。

# C 信号 V2 P14-A 参数敏感性实验

> 日期：2026-09-09  
> 口径：基于 `2026.09.09.1` 当前工作台最终入池结果做只读反事实分析，不修改策略常量，不重新生成快照。  
> 样本：`5501` 只当日有效股票，工作台有效事件 `4569` 条。

## 1. 实验结论

当前不建议立刻调低核心阈值。

原因是：可执行样本少，不是单一参数过严造成的。现有 `25` 条 Plan Gate 样本中，单独放松 `2R` 或 `8%` 止损阈值，都不会新增可执行样本；近似可放行的样本通常还同时存在量能确认不足、过热、距 MA20 过远等复合问题。

因此 P14-B 不应直接改参数，而应先做两件事：

1. 把拦截原因在前端解释清楚；
2. 对“旧 C 被 V2 拦截”的样本做更细的逐股复核，再判断是否存在稳定误杀。

## 3. 宏观门敏感性

参与候选池中，当前 `C回 / C突 / C爆` 共 `46` 条：

| 信号 | 数量 |
|---|---:|
| C回 | 25 |
| C突 | 20 |
| C爆 | 1 |

`C回` 的 MA60 约束：

| MA60 状态 | 数量 |
|---|---:|
| 价格低于 MA60，MA60 未上行 | 16 |
| 价格高于 MA60，但 MA60 未上行 | 7 |
| 价格高于 MA60，MA60 上行 | 2 |

结论：`C回` 的主要过滤器确实是 MA60 上行。当前只有 `000166` 申万宏源、`000828` 东莞控股满足并进入 `trade_ready`。短期不建议把 MA60 改成“只要站上即可”，因为这会把 7 个均线仍下行的样本提前放行，违背“回踩必须在中期结构未坏”的设计。

`C突` 的长周期约束：

| 项目 | 数量 |
|---|---:|
| `C突` 总数 | 20 |
| MA250 下方 | 14 |
| MA250 下行 | 13 |
| 周线 MACD 允许 | 16 |
| 周线 MACD 观察 | 4 |

结论：`C突` 被压制的主要来源是 MA250 趋势，而不是周 MACD。若后续发现低位反转型突破被大量误杀，不能简单取消 MA250；更合理的方向是单独定义“低位反转/破底翻突破”分支，并要求更严格的计划与量能确认。

`C爆` 当前只有 `688515` 裕太微 1 条进入 `trade_ready`。单样本不足以调攻击日阈值，P14-B 暂不应改 `C爆` 参数。

## 6. P14-B 决策结论

结论：本轮不进入代码调参。

决策理由：

- 放宽 `2R` 或 `8%` 止损不会增加反事实通过样本；
- 当前拦截是复合原因，不是单个阈值卡死；
- `C回` 的争议集中在 MA60 走平修复，属于状态分支问题，不是简单放松 MA60；
- `C突` 的争议集中在 MA250 下方低位反转，属于反转分支问题，不是简单取消 MA250；
- `strength_score >= 60` 不是主要瓶颈，目标选择优先级比强度阈值更值得复核。

因此 P14-B 当前冻结以下参数：

| 参数 | 当前决策 |
|---|---|
| 最低收益风险比 2R | 保持 |
| 止损距离上限 8% | 保持 |
| C回 MA60 上行约束 | 保持，后续只评估“走平修复”中间态 |
| C突/C爆 MA250 与周 MACD 门禁 | 保持，后续只评估“低位反转/破底翻”独立分支 |
| 阻力强度核心阈值 60 | 保持 |

后续按以下顺序推进：

1. `P16` 逐 K 线旧 C/V2 覆盖审计，确认最终入池口径是否隐藏了旧 C 触发；
2. 对 `C回` 中“站上 MA60 但 MA60 未上行”的 7 个样本做人工复核，判断是否需要增加“MA60 走平修复”中间态；
3. 对 `C突` 中“MA250 下方但破底翻/低位反转”的样本做人工复核，判断是否需要新增低位反转分支；
4. 若复核显示存在稳定误杀，再进入参数或分支策略改造。

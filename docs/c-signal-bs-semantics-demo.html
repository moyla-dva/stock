C信号不是B/S点

这份演示用 601330 的问题做例子：`风离` 是 Exit Gate 的风控动作语义，不是“明天一定跌”的预测。真正要落到交易执行，需要再经过持仓生命周期、计划门和防守线确认。

先把三层拆开

C研/C候/C修 研究、候选、修复。它们是证据层，不应该直接变成买卖动作。
C回/C突/C爆 可能进入 B 点候选，但必须通过 Plan Gate：目标、止损、收益风险比、环境许可。
C盈/减仓 触及强阻或过热时保护利润。它不是清仓 S 点，更多是仓位管理。
C风/风离 只有存在有效持仓生命周期且防守线失守，才应该升级成 S 离场。

601330 的 8月24日到底是什么

按当前本地重算数据，601330 在 2026-08-24 的日线截面确实触发 `风离`。原因是收盘价 7.01 跌破动态防守线 7.05；但 2026-08-27 又出现双底分型低点抬高，代表离场后进入新一轮结构修复观察。

当前可确认

2026-08-24 日线：收盘 7.01，动态防守线约 7.05，Exit Gate 为 `sell`。它是持仓风控动作，不是对后续全部走势的否定。

容易误读

如果只看单标签，会觉得系统一边给 `风离`，一边又承认底部抬高。拆分后应读成：8月24日旧持仓退出，8月27日新结构重新观察。

为什么“风离后上涨”仍然可能发生

风控信号处理的是“如果我已有仓位，是否还按原计划持有”。它保护的是亏损边界和利润回撤，不负责预测未来所有反弹。问题不在于风控会不会错过一段上涨，而在于它是否被正确显示为观察、减仓、还是 S 离场。

我建议的下一步改法

把 `C风` 从一个笼统标签，拆成图面可执行语义。这样既保留作者思路里的风险意识，又不会把所有风险事实都误读为卖点。

1. 风控观察 C风观察

顶分型、短线过热、局部背离，只显示风险观察，不显示 S。

2. 利润保护 减仓

已有持仓且触及强阻、过热、远离均线时，显示减仓或保护利润。

3. 真正离场 S离场

必须满足：存在有效 B 点生命周期，并且收盘跌破动态防守线或结构破位。

核心结论

`C` 是状态语言，`B/S` 是动作语言。系统下一步应当让状态先解释清楚，再由计划门和持仓生命周期转换成可执行动作。

C signal -> Gate -> Position -> B/S
